# 💰 Customer Lifetime Value Prediction (FLO)

Predicting future customer value is one of the most powerful applications of customer analytics. This project estimates **Customer Lifetime Value (CLTV)** using probabilistic models to help businesses identify high-value customers, optimize marketing investments, and improve long-term profitability.

---

## 🎯 Business Objective

Instead of evaluating customers solely by their past purchases, businesses need to estimate how much value each customer is expected to generate in the future.

This project applies **BG/NBD** and **Gamma-Gamma** probabilistic models to predict future customer value and support data-driven decision-making.

---

## 📂 Dataset

The project uses the **FLO Customer Dataset**, which contains transactional data from both online and offline shopping channels.

The dataset includes:

- Customer ID
- Order Frequency
- Purchase Dates
- Online & Offline Transactions
- Total Revenue

## 📈 Models Used

### BG/NBD Model

Estimates the expected number of future purchases for each customer.

### Gamma-Gamma Model

Predicts the average monetary value of future purchases.

By combining both models, the project estimates each customer's expected lifetime value.

## 📊 CLTV-Based Customer Strategy

The predicted CLTV scores can be transformed into actionable business strategies.

| Customer Group | Predicted CLTV | Business Goal | Recommended Action |
|----------------|---------------|---------------|--------------------|
| 💎 Platinum | Very High | Retain premium customers | VIP membership, exclusive campaigns, premium customer support |
| 🥇 Gold | High | Increase customer lifetime value | Personalized recommendations, cross-selling, loyalty rewards |
| 🥈 Silver | Medium | Encourage repeat purchases | Targeted promotions, personalized email campaigns |
| 🥉 Bronze | Low | Reactivate inactive customers | Discount campaigns, seasonal promotions, win-back offers |
